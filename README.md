# My Digital Poojavaeppu

A mobile-friendly, single-page website for a virtual Poojavaeppu celebration.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser while connected to the internet.
3. Choose a PDF (up to 35 MB) to place it on the virtual altar.
4. Select Interactive or Automatic pooja mode. Optional sound is off by default.

## Features
- Local PDF selection and first-page preview using PDF.js.
- Traditional Kerala-inspired altar, animated lamp, flowers, and celebration screen.
- Interactive and automatic pooja modes.
- Optional generated bell-like tones using Web Audio.
- Responsive mobile layout.
- PDF is processed in the browser; no upload server or account is used.

## Notes
- Google Fonts and PDF.js are loaded from CDNs, so internet access is needed for the full experience.
- Audio is synthesized locally and is not a recording of devotional music.
- This is a virtual experience, not a replacement for traditional religious practices.
